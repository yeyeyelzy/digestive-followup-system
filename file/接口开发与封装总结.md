# 接口开发与封装总结

## 一、封装目标与范围
本次按照三份接口设计文档完成了双端封装：
1. 多智能体端（Python）：提供稳定的内部 AI 接口，面向若依后端调用。
2. 若依后端（Java）：提供患者端、家属端、医生端对外接口，统一鉴权与权限校验。

重点覆盖模块：
1. 3D 心脏孪生体：实时 + 1~3 月预测。
2. 风险预测：风险等级 + 分布 + 文本说明。
3. 康复方案：AI 生成 + 医生修订 + 患者/家属查看。
4. 康复成就：healthy_today 聚合（对接 AI 布尔判定）。

---

## 二、接口封装方案（实施版）

### 2.1 分层方案
1. 小程序/前端 -> 若依后端（BFF）
2. 若依后端 -> 多智能体内部接口（HTTP）

其中：
1. 若依负责：鉴权、patientId 解析、家属绑定校验、统一响应。
2. 多智能体负责：计算与推理，返回标准 data 字段。

### 2.2 patientId 统一策略
1. 若依侧使用业务 patientId：10/11/12
2. 多智能体内部通过映射转换：
   - 10 -> P_001
   - 11 -> P_002
   - 12 -> P_003
