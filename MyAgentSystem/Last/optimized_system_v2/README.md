## ✨ 核心功能

### 1. 知识库RAG系统

- **哈希变更检测**: 系统启动时自动检测知识库文件变更
- **特征工程**: 自动构建文件级和片段级索引
- **多层级检索**: 标签过滤 → 关联召回 → 向量检索 → 结果重排序
- **系统自检**: 完整记录知识库构建和检索过程

### 2. 多智能体系统

- 8个核心智能体协同工作
- 支持患者端、家属端、医生端差异化输出
- 自动处理Fitabase数据并生成报告

### 3. 数据处理

- 支持时序生理数据（心率、步数、METs等）
- 支持临床数据、用药数据、饮食数据
- 自动分析患者状态并生成康复建议

## 🔧 配置说明

配置文件位于 `core/utils/config.py`，可调整：

- 数据路径
- 知识库参数
- 多智能体参数
- 输出路径

## 📝 注意事项

1. 首次运行会构建知识库索引，可能需要较长时间
2. 后续运行会通过哈希值检测变更，只处理新增/修改的文件
3. 所有输出文件都保存在 `output/` 目录下
4. 系统自检报告会详细记录知识库使用的文件和片段
