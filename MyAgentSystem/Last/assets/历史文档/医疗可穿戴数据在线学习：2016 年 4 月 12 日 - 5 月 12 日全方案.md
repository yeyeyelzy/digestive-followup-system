## 二、全流程数据预处理方案（适配在线流式学习）

### 2.1 预处理核心原则

- 流式适配：支持**每日增量数据处理**，无需全量数据重跑，适配在线学习闭环

- 时间对齐：所有数据统一时间戳格式，实现秒级-分钟级-日级数据的精准时间对齐，为关联分析提供基础

- 医学约束：所有预处理步骤符合临床数据规范，剔除无效值，保留医学意义上的有效波动

### 2.2 分步预处理流程

#### 步骤1：时间格式标准化与时区统一

1. 所有时间字段统一转换为`YYYY-MM-DD HH:MM:SS`格式，时区统一为患者所在时区

2. 拆分时间字段为「日期」「小时」「分钟」「秒」维度，方便不同粒度数据的聚合与对齐

3. 针对跨天数据（如夜间睡眠），统一按「自然日+睡眠周期」双维度标记，避免数据拆分错误

#### 步骤2：脏数据与无效值清洗

|数据类型|无效值判定规则|处理方式|
|---|---|---|
|心率数据|心率值<30次/分或>220次/分、连续5分钟以上数值无变化、空值|无效值剔除，短时间缺失用线性插值填充，长时间缺失标记为「数据缺失」|
|步数数据|步数值<0、空值|无效值置0，连续缺失标记为「数据缺失」|
|METs数据|METs值<0.8（静息状态下限）、空值|无效值置1.0，连续缺失标记为「数据缺失」|
|睡眠数据|睡眠分期值不在预设范围内、空值|无效值标记为「醒觉」，连续缺失标记为「睡眠数据缺失」|
#### 步骤3：多源数据时间对齐与融合

1. 主时间轴：以分钟级时间轴为基准，覆盖全天24小时1440个分钟节点

2. 数据聚合：秒级心率数据聚合为分钟级平均心率，匹配分钟级时间轴

3. 特征融合：将分钟级心率、步数、METs、睡眠分期数据，按时间戳合并为宽表，实现同一时间点多指标的一一对应，为后续关联归因分析提供基础

4. 日级聚合：基于分钟级数据，按自然日聚合生成日级核心指标表，匹配dailyActivity、sleepDay等日级汇总数据

#### 步骤4：场景标签化处理

为每个分钟级数据添加场景标签，实现个性化阈值的分场景计算：

- 睡眠场景：基于睡眠日志标记的睡眠时段，进一步拆分「入睡期、深睡期、浅睡期、醒觉期」

- 运动场景：基于METs值拆分「久坐（METs<1.5）、低强度活动（1.5≤METs<3）、中等强度活动（3≤METs<6）、高强度活动（METs≥6）」

- 静息场景：非睡眠、非运动的久坐时段，用于计算静息心率基线

## 三、核心Online Learning在线学习算法体系

本体系为项目核心，完全实现「初始基线初始化→每日增量学习→个性化阈值动态更新→风险分级→病情评估→区间预测」的闭环在线学习，完全适配患者个性化病情，而非通用医学标准。

### 3.1 患者基线初始化（先验知识注入）

**输入**：patient_info.json患者初始就诊信息

**输出**：患者个性化初始基线库，为在线学习提供先验基准

1. 通用医学基线注入：参考《中国心血管病健康管理指南》等权威指南，设定各指标的硬边界（如成人心率硬边界30-220次/分，静息心率通用正常范围60-100次/分）

2. 个性化初始基线校准：基于患者就诊时的诊断、基础疾病、初始生命体征，调整初始基线范围。例如：

    - 心衰患者：初始静息心率基线放宽至55-110次/分，治疗目标为逐步降至70次/分以下

    - 高血压患者：初始运动心率上限按「220-年龄」的80%设定

3. 病情评估基准设定：明确患者病情好转/恶化的核心判定维度，例如：

    - 正向指标（越高越好，代表好转）：睡眠效率、中高强度活动时长、总步数、深睡占比、心率变异性

    - 负向指标（越低越好，代表好转）：静息心率、心率波动率、久坐时长、睡眠中断次数、红色预警事件次数

4. 初始模型参数设定：前3天（4.12-4.14）为模型预热期，基于预热期稳定数据，计算各指标的初始均值μ₀、标准差σ₀，作为在线学习的起点。

### 3.2 在线增量学习核心算法（贝叶斯流式更新）

采用**带遗忘因子的贝叶斯在线更新算法**，适配流式数据，越近期的数据权重越高，可实时捕捉患者病情变化，无需全量数据重训。

#### 3.2.1 算法核心公式

针对每个指标（如静息心率、日步数、睡眠效率），每日完成一次模型更新：

1. 当日增量数据统计：计算当日该指标的均值`μ_new`、标准差`σ_new`

2. 后验分布在线更新：

     $\mu_t = \alpha \times \mu_{t-1} + (1-\alpha) \times \mu_{new}$ 

     $\sigma_t = \sqrt{\alpha \times \sigma_{t-1}^2 + (1-\alpha) \times \sigma_{new}^2 + \alpha(1-\alpha)(\mu_{t-1}-\mu_{new})^2}$ 

    - 核心参数：`α`为遗忘因子，取值0.7-0.9，数值越高，历史数据权重越高，模型越稳定；数值越低，近期数据权重越高，对病情变化越敏感。慢病管理推荐初始值0.8，病情急性期可下调至0.7

    - `μ_t`：更新后当日的指标均值基线

    - `σ_t`：更新后当日的指标波动标准差

3. 医学硬边界约束：更新后的`μ_t`必须限制在指南规定的硬边界内，避免算法异常导致的不合理基线。

#### 3.2.2 三级风险区间划分（蓝/黄/红预警）

基于更新后的`μ_t`和`σ_t`，为每个指标划分个性化三级预警区间，同时区分场景（如静息/运动/睡眠心率分别计算区间）：

|预警等级|区间范围|风险定义|处理规则|
|---|---|---|---|
|蓝色安全区间| $[\mu_t - 1\sigma_t, \mu_t + 1\sigma_t]$ |正常个性化波动，无风险|无预警，纳入基线更新|
|黄色关注区间| $[\mu_t - 2\sigma_t, \mu_t - 1\sigma_t) ∪ (\mu_t + 1\sigma_t, \mu_t + 2\sigma_t]$ |轻度异常，偏离个性化基线，需关注|记录事件，归因分析，报告提示|
|红色预警区间| $(-∞, \mu_t - 2\sigma_t) ∪ (\mu_t + 2\sigma_t, +∞)$ |重度异常，显著偏离基线，高风险|高亮预警，详细归因，医学建议|
#### 3.2.3 趋势修正与区间预测

针对次日健康区间预测，加入趋势修正逻辑：

- 若指标呈持续好转趋势（如静息心率连续3天下降），次日安全区间向好转方向微调，同时收紧预警阈值，放大改善效果

- 若指标呈持续加重趋势（如红色预警事件连续增加），次日安全区间收紧，预警阈值下调，更早识别异常

- 最终输出每个核心指标的次日蓝/黄/红三级预测区间，写入报告的健康指引模块。

### 3.3 异常点关联归因分析算法

解决用户核心需求：区分心率异常是生理性（运动、饮食）还是病理性，在报告中明确标注异常原因。

1. 时间精准对齐：将黄色/红色异常心率时段，与同时段的步数、METs、睡眠数据做1分钟级时间对齐

2. 多维度归因规则库：

|    异常时段场景|    判定规则|    归因结论|
|---|---|---|
|    运动场景|    异常时段METs≥3或步数>100步/分钟，且心率与运动强度匹配（同强度历史心率波动±10%）|    运动相关性心率升高，生理性波动，无风险|
|    运动异常场景|    异常时段METs≥3，心率超出同强度运动历史区间20%以上|    运动中心率异常升高，需关注心肺功能，病理性待排查|
|    睡眠场景|    异常时段处于睡眠期，无醒觉记录，心率超出睡眠基线|    睡眠中心率异常，需排查夜间缺氧/心律失常|
|    静息异常场景|    异常时段为非睡眠、非运动的久坐状态，心率超出静息基线|    静息状态心率异常，病理性待排查，需关注基础疾病变化|
3. 归因结果标注：在心率趋势图中对异常点进行标注，同时在报告中详细说明异常时段、异常值、归因结论与注意事项。

### 3.4 病情进展动态评估模型

实现用户需求的「每日/每周/每月判断患者病情是否变好」，输出明确的病情评估结论。

1. 每日健康评分模型：

    - 初始评分：基于患者就诊时的病情严重程度，初始分为50分（满分100分）

    - 评分更新规则：正向指标每提升1个标准差，+2分；负向指标每下降1个标准差，+2分；反之则对应扣分

    - 事件扣分：单次红色预警事件-5分，单次黄色关注事件-2分

2. 病情趋势判定：

    - 病情好转：连续3天健康评分上升，核心正向指标改善，负向指标下降

    - 病情稳定：健康评分波动幅度≤5分，核心指标无显著异常，预警事件无增加

    - 病情加重：连续3天健康评分下降，核心负向指标恶化，预警事件显著增加

3. 周期对比评估：

    - 日对比：当日指标vs前一日指标

    - 周对比：当周平均指标vs上一周平均指标

    - 月对比：全周期指标vs初始就诊基线，评估整体治疗效果

## 四、日/周/月报告体系与图文排版规范

### 4.1 通用报告设计原则

- 图文并茂：核心指标100%配套可视化图表，文字结论与图表一一对应

- 分层呈现：先核心概览，再分模块详细分析，最后风险提示与健康指引

- 医学严谨：所有结论均有数据支撑，异常事件明确归因，区分生理性/病理性

- 在线适配：报告内容完全基于当日更新的在线学习基线，体现个性化动态评估

### 4.2 日报详细设计（每日生成，单份固定结构）

#### 报告结构（6个核心模块）

##### 模块1：报告头与当日核心概览

- 固定内容：患者ID、报告日期、当日健康评分、病情总体评估（好转/稳定/加重）、当日预警事件汇总（红色X次、黄色X次）

- 呈现形式：纯文本卡片式布局，无图，核心信息一眼可见

##### 模块2：当日心血管指标监测与分析（核心模块，必配可视化）

- 文字内容：

    1. 当日心率核心指标：平均心率、静息心率、最大心率、最小心率、心率波动范围、心率变异性

    2. 异常事件统计：红/黄预警事件次数、持续时长、分布时段、归因分析汇总

    3. 周期对比：与前一日、初始基线的指标变化幅度与趋势说明

    4. 次日预测：次日心率分场景（静息/运动/睡眠）的蓝/黄/红三级区间

- 配套可视化（2张核心图）：

    1. **当日24小时心率趋势图**（必选，matplotlib绘图规范见第五章）

        - 核心要求：X轴为24小时时间轴，Y轴为心率值，背景标注蓝/黄/红三级区间，黑色曲线为实时心率，标注异常点与归因，辅助线标注平均心率、静息心率

    2. **当日心率分布直方图**（可选）：展示当日心率值在三级区间的占比分布

##### 模块3：当日运动与代谢监测与分析

- 文字内容：

    1. 当日运动核心指标：总步数、总活动距离、各强度活动时长、总卡路里消耗、平均METs

    2. 关联分析：运动时段与心率变化的匹配度分析，运动后心率恢复速度评估

    3. 周期对比：与前一日、运动目标的达成情况对比

    4. 次日运动建议：推荐运动强度、时长、安全心率区间

- 配套可视化：

    1. 当日24小时步数/METs趋势图（与心率趋势图时间轴完全对齐，方便关联分析）

    2. 当日活动强度占比饼图（高强度/中强度/低强度/久坐时长占比）

##### 模块4：当日睡眠监测与分析

- 文字内容：

    1. 当日睡眠核心指标：总睡眠时长、卧床时长、睡眠效率、睡眠分期占比、睡眠中断次数、入睡潜伏期

    2. 睡眠中心率分析：睡眠时段心率波动、异常事件与归因

    3. 周期对比：与前一日、睡眠目标的对比

    4. 次日睡眠健康指引

- 配套可视化：

    1. 当日睡眠分期时序图（与睡眠时段心率趋势图上下对齐）

    2. 睡眠分期占比饼图

##### 模块5：其他指标监测

- 文字内容：体重/BMI变化、海拔与活动关联分析，与初始基线的对比

- 配套可视化：体重变化趋势图（日报为单点标注，周报/月报为连续趋势线）

##### 模块6：健康评估与明日指引

- 文字内容：

    1. 当日病情总体评估：明确结论（好转/稳定/加重），与初始基线、前一日的对比总结

    2. 风险提示：红色/黄色预警事件的详细说明、医学注意事项

    3. 明日健康区间：所有核心指标的蓝/黄/红三级预测区间

    4. 个性化健康建议：基于当日数据的运动、睡眠、生活方式、用药提醒建议

### 4.3 周报详细设计（每周生成）

核心定位：周度趋势分析、风险汇总、阶段病情评估，结构如下：

1. 报告头与周度核心概览：报告周期、周平均健康评分、周度病情总体评估、周度预警事件汇总

4. 周度病情进展评估：与上一周、初始基线的对比，指标改善/恶化情况，总体趋势判定

```Python

import matplotlib.pyplot as plt
import matplotlib.dates as mdates
import numpy as np

def plot_daily_hr_trend(date, time_axis, hr_data, baseline, abnormal_points, save_path):
    """
    绘制每日24小时心率趋势图
    :param date: 报告日期，如'2016-04-12'
    :param time_axis: 时间轴数组，datetime格式
    :param hr_data: 分钟级心率数据数组
    :param baseline: 在线学习输出的三级区间字典，含blue_low/blue_high/yellow_low/yellow_high/red_low/red_high/rest_hr
    :param abnormal_points: 异常点DataFrame，含time、hr、level、attribution
    :param save_path: 图片保存路径
    """
    # 加载全局配置
    plt.rcParams.update(GLOBAL_CONFIG['rc_params'])
    
    # 初始化画布
    fig, ax = plt.subplots(figsize=GLOBAL_CONFIG['fig_size'], dpi=GLOBAL_CONFIG['dpi'])
    
    # 1. 绘制三级预警区间背景
    ax.axhspan(baseline['blue_low'], baseline['blue_high'], 
               color=GLOBAL_CONFIG['colors']['blue'], alpha=0.15, label='安全区间')
    ax.axhspan(baseline['yellow_low'], baseline['blue_low'], 
               color=GLOBAL_CONFIG['colors']['yellow'], alpha=0.15, label='关注区间')
    ax.axhspan(baseline['blue_high'], baseline['yellow_high'], 
               color=GLOBAL_CONFIG['colors']['yellow'], alpha=0.15)
    ax.axhspan(baseline['red_low'], baseline['yellow_low'], 
               color=GLOBAL_CONFIG['colors']['red'], alpha=0.15, label='预警区间')
    ax.axhspan(baseline['yellow_high'], baseline['red_high'], 
               color=GLOBAL_CONFIG['colors']['red'], alpha=0.15)
    
    # 2. 绘制心率曲线
    ax.plot(time_axis, hr_data, color=GLOBAL_CONFIG['colors']['hr_line'], 
            linewidth=0.8, label='实时心率')
    
    # 3. 绘制辅助线
    avg_hr = np.mean(hr_data)
    rest_hr = baseline['rest_hr']
    ax.axhline(avg_hr, color=GLOBAL_CONFIG['colors']['avg_line'], 
               linestyle='--', linewidth=1.2, label=f'当日平均心率: {avg_hr:.0f}次/分')
    ax.axhline(rest_hr, color=GLOBAL_CONFIG['colors']['rest_line'], 
               linestyle='--', linewidth=1.2, label=f'静息心率: {rest_hr:.0f}次/分')
    
    # 4. 异常点标注
    # 红色预警点
    red_points = abnormal_points[abnormal_points['level'] == 'red']
    ax.scatter(red_points['time'], red_points['hr'], 
               color=GLOBAL_CONFIG['colors']['red'], s=20, zorder=5)
    for _, point in red_points.iterrows():
        ax.text(point['time'], point['hr'] + 5, point['attribution'], 
                fontsize=8, color=GLOBAL_CONFIG['colors']['red'])
    # 黄色关注点
    yellow_points = abnormal_points[abnormal_points['level'] == 'yellow']
    ax.scatter(yellow_points['time'], yellow_points['hr'], 
               color=GLOBAL_CONFIG['colors']['yellow'], s=15, zorder=4)
    
    # 5. 坐标轴与格式设置
    ax.set_title(f'患者P_001 {date} 24小时心率趋势图', fontweight='bold')
    ax.set_xlabel('时间')
    ax.set_ylabel('心率 (次/分)')
    ax.set_ylim(baseline['red_low'], baseline['red_high'])
    # X轴时间格式设置，每2小时一个刻度
    ax.xaxis.set_major_formatter(mdates.DateFormatter('%H:%M'))
    ax.xaxis.set_major_locator(mdates.HourLocator(interval=2))
    plt.xticks(rotation=45)
    # 网格设置
    ax.grid(axis='x', linestyle='--', color=GLOBAL_CONFIG['colors']['grid'], alpha=0.3)
    # 图例
    ax.legend(loc='upper right', bbox_to_anchor=(1, 1))
    
    # 6. 保存图片
    plt.tight_layout()
    plt.savefig(save_path, bbox_inches='tight')
    plt.close()
```

### 6.2 每日闭环执行流程

1. 每日0点，数据处理智能体接入前一日全量增量数据，完成预处理、时间对齐、特征提取，输出标准化数据集

2. 在线学习智能体加载前序模型参数，完成当日数据的模型更新、三级区间计算、风险分级、病情评估、次日区间预测

3. 医学专业智能体对所有结果进行医学合规性校验，完成异常事件归因分析，生成健康建议与风险提示

4. 可视化智能体基于当日数据与分析结果，自动生成报告所需的所有图表

5. 报告生成智能体整合所有内容，按固定模板生成当日日报，输出PDF文件

6. 每周日/每月最后一天，触发周报/月报生成流程，完成周期汇总与全量评估
