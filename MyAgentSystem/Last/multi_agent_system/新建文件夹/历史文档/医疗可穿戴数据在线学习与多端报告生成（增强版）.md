### 1.2 在线学习的数学原理深化（医疗场景定制）

#### 1.2.1 贝叶斯在线更新+强化学习累计奖励的数学融合

**核心目标**：将「每日病情评估（好转/稳定/恶化）」转化为强化学习的奖励信号，结合贝叶斯在线更新实现动态基线+累计加分的闭环。

1. **贝叶斯在线更新（带遗忘因子）数学推导**

对任意指标 $X$ （如静息心率），定义：

- 先验分布： $p(\mu_{t-1}, \sigma_{t-1}) \sim \mathcal{N}(\mu_{t-1}, \sigma_{t-1}^2)$ （正态分布）

- 当日增量数据似然： $p(X_{new} | \mu_{new}, \sigma_{new}) \sim \mathcal{N}(\mu_{new}, \sigma_{new}^2)$ 

- 后验分布更新（共轭先验）：

     $\mu_t = \alpha \mu_{t-1} + (1-\alpha) \mu_{new}$ 

     $\sigma_t^2 = \alpha \sigma_{t-1}^2 + (1-\alpha) \sigma_{new}^2 + \alpha(1-\alpha)(\mu_{t-1}-\mu_{new})^2$ 

    其中：

    -  $\alpha$ ：遗忘因子（疾病定制：心衰 $\alpha=0.7$ ，高血压 $\alpha=0.8$ ，糖尿病 $\alpha=0.75$ ）

    - 医学约束： $\mu_t \in [X_{min}^{med}, X_{max}^{med}]$ （如心衰静息心率 $\mu_t \in [55, 110]$ ）

1. **强化学习累计加分策略数学表达**

定义患者每日健康评分 $S_t$ （初始分 $S_0=50$ ，满分100）：

 $S_t = S_{t-1} + \sum_{i=1}^n w_i \cdot \Delta Z_i - \sum_{j=1}^m k_j \cdot E_j$ 

-  $n$ ：核心评估指标数（如心率、睡眠、运动）； $w_i$ ：指标 $i$ 的权重（医疗定制：心衰 $w_{心率}=0.4$ ，糖尿病 $w_{运动}=0.35$ ）；

-  $\Delta Z_i$ ：指标 $i$ 的标准化变化（ $\Delta Z_i = \frac{X_{i,ref} - X_{i,t}}{\sigma_{i,t}}$ ， $X_{i,ref}$ 为医疗目标值，正向指标取反）；

-  $m$ ：预警事件数； $k_j$ ：事件 $j$ 的扣分权重（红色预警 $k=5$ ，黄色预警 $k=2$ ，昏迷预警 $k=10$ ）； $E_j$ ：事件 $j$ 的发生次数。

1. **次日区间预测的数学模型（置信区间+趋势修正）**

基于后验分布和趋势项，次日指标 $X_{t+1}$ 的三级区间：

 $\begin{cases}
蓝色安全区间：[\mu_t + \beta \cdot \tau_t - 1\sigma_t, \mu_t + \beta \cdot \tau_t + 1\sigma_t] \\
黄色关注区间：[\mu_t + \beta \cdot \tau_t - 2\sigma_t, \mu_t + \beta \cdot \tau_t - 1\sigma_t) \cup (\mu_t + \beta \cdot \tau_t + 1\sigma_t, \mu_t + \beta \cdot \tau_t + 2\sigma_t] \\
红色预警区间：(-\infty, \mu_t + \beta \cdot \tau_t - 2\sigma_t) \cup (\mu_t + \beta \cdot \tau_t + 2\sigma_t, +\infty)
\end{cases}$ 

其中 $\tau_t$ 为趋势项（ $\tau_t = \frac{\mu_t - \mu_{t-3}}{3}$ ，连续3天趋势）， $\beta$ 为趋势修正系数（好转 $\beta=-0.1$ ，恶化 $\beta=0.1$ ，稳定 $\beta=0$ ）。

#### 1.2.2 多指标冲突的数学解决（数据分布+权重融合）

针对「心率好转但运动数据恶化」等冲突场景，采用**加权多维度评估+分布相似度检验**：

1. 指标权重动态调整： $w_i = w_{i,med} \cdot \gamma_i$ ，其中 $\gamma_i = \frac{1 - p_i}{1 - \bar{p}}$ （ $p_i$ 为指标 $i$ 的数据缺失率， $\bar{p}$ 为平均缺失率）；

2. 分布相似度检验：采用KS检验（Kolmogorov-Smirnov）对比当日指标分布与基线分布， $p<0.05$ 判定为「分布显著异常」，提升该指标权重；

3. 最终病情判定：基于加权评分的熵权法（Entropy Weight Method）融合多指标结论，避免单一指标误导。

### 2.2 集成学习：智能体权重动态调整算法

#### 2.2.1 权重计算核心逻辑

采用**动态加权集成（DWE）** 算法，权重由三部分加权得到：

 $W_a(t) = \lambda \cdot W_{a,med} + (1-\lambda) \cdot (0.6 \cdot W_{a,acc} + 0.4 \cdot W_{a,urg})$ 

-  $W_a(t)$ ：智能体 $a$ 在 $t$ 时刻的权重；

-  $\lambda$ ：医疗规则权重系数（固定0.5，保证医疗优先级）；

-  $W_{a,med}$ ：疾病定制的智能体基础权重（如医学专业智能体 $W=0.8$ ，可视化智能体 $W=0.1$ ）；

-  $W_{a,acc}$ ：智能体历史预测准确率（ $W_{a,acc} = \frac{TP+TN}{TP+TN+FP+FN}$ ，每日更新）；

-  $W_{a,urg}$ ：紧急度权重（高危事件时，风险分级智能体 $W_{a,urg}=1.0$ ，常规时 $W_{a,urg}=0.5$ ）。

#### 2.2.2 权重更新触发条件（LangGraph状态监听）

1. 每日例行更新：凌晨1点基于前一日所有智能体的准确率和事件紧急度更新权重；

2. 高危事件触发：检测到红色预警/昏迷事件时，立即提升医学专业智能体、风险分级智能体权重至0.9；

3. 数据异常触发：数据缺失率>30%时，提升数据质量智能体权重至0.7，降低在线学习智能体权重至0.3；

4. 医生反馈触发：医生修正报告结论后，反向调整对应智能体权重（如修正归因结论，降低在线学习权重0.1，提升医学专业权重0.1）。

#### 2.2.3 多指标冲突的智能体决策融合

当不同智能体结论冲突（如心率智能体判定好转，运动智能体判定恶化），采用**加权投票+医疗规则否决**：

1. 加权投票： $V = \sum W_a \cdot V_a$ （ $V_a$ 为智能体 $a$ 的投票结果，1=好转，0=稳定，-1=恶化）；

2. 医疗规则否决：若核心医疗指标（如心衰患者静息心率）触发红色预警，直接判定为「恶化」，无视投票结果；

3. 最终结论： $V \geq 0.3$ =好转， $-0.3 < V < 0.3$ =稳定， $V \leq -0.3$ =恶化。

```Python
from langgraph.graph import StateGraph, END
import pandas as pd
import numpy as np

# 定义状态结构
class AgentState:
    patient_id: str
    date: str
    agent_weights: dict  # 智能体权重矩阵
    indicator_weights: dict  # 指标权重矩阵
    health_score: float
    risk_level: str
    high_risk_events: list

# 权重计算节点
def calculate_agent_weights(state: AgentState) -> AgentState:
    """
    动态计算智能体权重（基于准确率+医疗规则+紧急度）
    """
    # 1. 加载历史准确率（从日志读取）
    agent_acc = pd.read_csv(f'patients/{state.patient_id}/system_check/agent_performance.csv')
    acc_dict = dict(zip(agent_acc['agent_name'], agent_acc['accuracy']))
    
    # 2. 医疗基础权重
    med_weights = {
        '医学专业智能体': 0.8,
        '风险分级智能体': 0.7,
        '在线学习智能体': 0.6,
        '数据处理智能体': 0.5,
        '可视化智能体': 0.1
    }
    
    # 3. 紧急度权重（高危事件时提升风险/医学智能体）
    urg_weights = {k: 1.0 if k in ['医学专业智能体', '风险分级智能体'] and state.high_risk_events else 0.5 
                   for k in med_weights.keys()}
    
    # 4. 动态权重计算
    lambda_ = 0.5  # 医疗规则权重系数
    agent_weights = {}
    for agent in med_weights.keys():
        w_acc = acc_dict.get(agent, 0.5)
        w_urg = urg_weights[agent]
        agent_weights[agent] = lambda_ * med_weights[agent] + (1-lambda_) * (0.6*w_acc + 0.4*w_urg)
    
    # 5. 归一化权重
    total = sum(agent_weights.values())
    agent_weights = {k: v/total for k, v in agent_weights.items()}
    
    state.agent_weights = agent_weights
    return state

# 构建LangGraph
graph = StateGraph(AgentState)
graph.add_node("calculate_weights", calculate_agent_weights)
graph.add_edge("calculate_weights", END)

# 运行
initial_state = AgentState(
    patient_id='P_001',
    date='2016-04-12',
    agent_weights={},
    indicator_weights={},
    health_score=50.0,
    risk_level='blue',
    high_risk_events=[]
)
app = graph.compile()
result = app.invoke(initial_state)
print(f"智能体权重：{result.agent_weights}")
```

```Python
def rank_patients(patient_list, date):
    """
    医生端患者恶化排序（越高越需关注）
    :param patient_list: 患者ID列表 list
    :param date: 排序日期 str
    :return: 排序后的患者列表+评分 DataFrame
    """
    rank_data = []
    for pid in patient_list:
        # 1. 加载当日健康评分
        daily_report = pd.read_csv(f'patients/{pid}/doctor_end/daily/{date}.csv')
        health_score = daily_report['health_score'].iloc[0]
        score_change = daily_report['score_change'].iloc[0]  # 与昨日比变化
        
        # 2. 预警事件次数
        red_count = daily_report['red_warning_count'].iloc[0]
        yellow_count = daily_report['yellow_warning_count'].iloc[0]
        
        # 3. 核心指标恶化程度（标准化）
        hr_worsen = daily_report['hr_worsen'].iloc[0]  # 心率恶化程度（0-1）
        sleep_worsen = daily_report['sleep_worsen'].iloc[0]  # 睡眠恶化程度（0-1）
        activity_worsen = daily_report['activity_worsen'].iloc[0]  # 运动恶化程度（0-1）
        
        # 4. 恶化评分计算（越高越差）
        worsen_score = (
            max(0, -score_change) * 0.3 +  # 评分下降幅度
            red_count * 0.4 +  # 红色预警权重最高
            yellow_count * 0.1 +
            (hr_worsen + sleep_worsen + activity_worsen)/3 * 0.2
        )
        
        rank_data.append({'patient_id': pid, 'worsen_score': worsen_score, 'red_count': red_count})
    
    # 排序
    rank_df = pd.DataFrame(rank_data).sort_values('worsen_score', ascending=False)
    rank_df['rank'] = range(1, len(rank_df)+1)
    
    # 保存到全局目录
    rank_df.to_csv(f'global/patient_ranking_daily.csv', index=False)
    return rank_df
```
