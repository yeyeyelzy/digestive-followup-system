# 智能体设计文档

## 1. 系统架构

本项目采用多智能体系统架构，基于LangGraph构建，包含以下智能体：

| 智能体名称 | 职责 | 核心功能 |
|-----------|------|----------|
| BioSensingAgent | 生理感知 | 分析心率、血压等生理数据 |
| ContextAwareAgent | 情境感知 | 分析环境数据和活动场景 |
| ClinicalPlannerAgent | 临床规划 | 制定康复计划和医疗建议 |
| ProactiveInteractionAgent | 主动交互 | 生成患者交互内容 |
| CoordinatorAgent | 协调管理 | 协调其他智能体的工作 |
| VisionAgent | 视觉分析 | 分析视频数据，检测摔倒 |
| **AltitudeAgent** | **海拔处理** | **分析海拔数据，检测摔倒和运动情况** |
| **OutputAgent** | **输出管理** | **生成日报、周报、月报，为不同端提供输出** |

## 2. 新增智能体详细设计

### 2.1 AltitudeAgent（海拔处理智能体）

#### 2.1.1 角色定位
- **角色**：海拔数据分析专家
- **职责**：分析海拔数据，检测摔倒和运动情况
- **协作**：与VisionAgent一起检测老人摔倒，与BioSensingAgent一起检测运动情况

#### 2.1.2 核心功能

1. **海拔数据处理**
   - 支持从文件或内存中加载海拔数据
   - 处理不同格式的海拔数据文件（Excel、CSV）

2. **摔倒检测**
   - 基于海拔变化率检测摔倒事件
   - 定义摔倒阈值：短时间内海拔快速下降
   - 提取摔倒时间点和详细信息

3. **运动分析**
   - 分析运动强度和频率
   - 检测过度运动情况
   - 评估运动模式的合理性

4. **数据可视化**
   - 生成海拔变化趋势图表
   - 提供运动强度分布分析

#### 2.1.3 输入输出

**输入**：
- 海拔数据文件路径或数据帧
- 其他相关数据（如视频分析结果）

**输出**：
- 摔倒检测结果和详细信息
- 运动分析结果（强度、是否过度运动）
- 分析摘要和建议

#### 2.1.4 使用示例

```python
from agents.altitude_agent import AltitudeAgent

# 创建海拔处理智能体实例
altitude_agent = AltitudeAgent()

# 处理海拔数据
state = {
    'altitude_file': 'path/to/altitude_data.xlsx'
}

result = altitude_agent.process(state)
print(result['altitude_analysis'])
```

### 2.2 OutputAgent（输出智能体）

#### 2.2.1 角色定位
- **角色**：报告生成专家
- **职责**：生成日报、周报、月报，并为不同端提供输出
- **目标**：为患者、家属和医生提供个性化的健康报告

#### 2.2.2 核心功能

1. **多维度报告生成**
   - **日报**：每日健康状况分析
   - **周报**：每周健康趋势分析
   - **月报**：每月健康总结和建议

2. **多端输出**
   - **患者端**：简洁易懂的健康报告，关注个人健康状况
   - **家属端**：详细的健康监测报告，包含紧急警报
   - **医生端**：专业的医疗分析报告，包含风险评估和建议

3. **数据可视化**
   - 使用matplotlib生成各种图表：
     - 心率变化趋势图
     - 睡眠质量曲线
     - 运动量曲线
     - 运动强度分布饼状图
     - 海拔变化趋势图

4. **智能排序**
   - 为医生端提供患者风险排序
   - 优先显示病情恶化的患者
   - 帮助医生高效管理多个患者

5. **紧急警报**
   - 为家属端提供紧急情况警报
   - 包含摔倒事件的时间和截图
   - 提供及时的通知和建议

#### 2.2.3 输入输出

**输入**：
- 患者基本信息
- 生理数据（心率、血压等）
- 睡眠数据
- 活动数据
- 海拔分析结果
- 视觉分析结果
- 临床分析结果

**输出**：
- 患者端报告（日报、周报、月报）
- 家属端报告（日报、周报、月报、紧急警报）
- 医生端报告（日报、周报、月报、医疗建议、风险评分）
- 各种健康数据图表（base64编码）

#### 2.2.4 使用示例

```python
from agents.output_agent import OutputAgent

# 创建输出智能体实例
output_agent = OutputAgent()

# 准备数据
state = {
    'patient_data': {
        'patient_id': 'P_001',
        'name': '王志强',
        'age': 58
    },
    'bio_data': {
        'heart_rate': {'average': 75},
        'blood_pressure': {'systolic': 120, 'diastolic': 80}
    },
    'sleep_data': {
        'duration': 7.5,
        'quality': '良好'
    },
    'activity_data': {
        'steps': 8000,
        'duration': 60
    },
    'altitude_analysis': {
        'fall_detected': False,
        'motion_analysis': {
            'exercise_intensity': 'moderate',
            'over_exercise': False
        }
    },
    'vision_analysis': {
        'fall_detected': False
    },
    'clinical_analysis': {
        'primary_diagnosis': '冠状动脉粥样硬化性心脏病'
    }
}

# 生成报告
result = output_agent.process(state)
print(result['output']['reports'])
```

## 3. 智能体协作流程

### 3.1 数据处理流程

1. **数据采集**：收集患者的生理数据、睡眠数据、活动数据、视频数据和海拔数据
2. **数据预处理**：对原始数据进行清洗和格式化
3. **智能体分析**：
   - BioSensingAgent分析生理数据
   - ContextAwareAgent分析情境数据
   - VisionAgent分析视频数据
   - **AltitudeAgent分析海拔数据**
   - ClinicalPlannerAgent制定康复计划
4. **结果融合**：CoordinatorAgent融合各智能体的分析结果
5. **输出生成**：**OutputAgent生成多端报告**
6. **交互响应**：ProactiveInteractionAgent生成患者交互内容

### 3.2 摔倒检测协作

1. **VisionAgent**：通过视频分析检测摔倒
2. **AltitudeAgent**：通过海拔变化检测摔倒
3. **结果融合**：CoordinatorAgent综合两个智能体的结果，提高检测准确性
4. **输出警报**：OutputAgent为家属端生成紧急警报

### 3.3 运动分析协作

1. **BioSensingAgent**：分析心率等生理指标
2. **AltitudeAgent**：分析海拔变化和运动强度
3. **结果融合**：CoordinatorAgent综合分析运动是否过度
4. **输出建议**：OutputAgent生成运动建议和预警

## 4. 报告生成系统

### 4.1 报告类型

| 报告类型 | 生成频率 | 目标用户 | 核心内容 |
|----------|----------|----------|----------|
| 日报 | 每日 | 患者、家属、医生 | 当日健康状况分析 |
| 周报 | 每周 | 患者、家属、医生 | 每周健康趋势分析 |
| 月报 | 每月 | 患者、家属、医生 | 每月健康总结和建议 |

### 4.2 报告内容

#### 4.2.1 患者端报告
- **文字部分**：健康状况总结、运动建议、睡眠建议
- **图表部分**：心率趋势、睡眠质量、运动量曲线
- **特点**：简洁易懂，关注个人健康状况

#### 4.2.2 家属端报告
- **文字部分**：详细健康监测数据、异常情况提醒
- **图表部分**：同患者端
- **特殊功能**：紧急警报（摔倒检测、异常生理指标）
- **特点**：详细全面，包含紧急情况通知

#### 4.2.3 医生端报告
- **文字部分**：专业医疗分析、风险评估、治疗建议
- **图表部分**：同患者端，加上医疗专业图表
- **特殊功能**：患者风险排序、专业医疗建议
- **特点**：专业详细，支持多患者管理

## 7. 使用指南

### 7.1 基本使用

```python
from agents.coordinator import CoordinatorAgent

# 创建协调智能体实例
coordinator = CoordinatorAgent()

# 准备患者数据
patient_data = {
    'patient_id': 'P_001',
    'name': '王志强',
    'age': 58,
    'gender': 'M'
}

# 处理数据
result = coordinator.process(patient_data)
print(result)
```

### 7.2 高级使用

```python

from agents.output_agent import OutputAgent

# 创建海拔处理智能体
altitude_agent = AltitudeAgent()

# 处理海拔数据

    'altitude_file': 'path/to/altitude_data.xlsx'

    'patient_data': patient_data,
    'altitude_analysis': altitude_result['altitude_analysis'],
    # 其他数据...
})

# 获取不同端的报告
patient_report = output_result['output']['reports']['patient']

```
