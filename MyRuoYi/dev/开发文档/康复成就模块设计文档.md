# 康复成就模块设计文档

## 1. 模块概述
康复成就模块旨在通过游戏化的激励机制，鼓励患者坚持健康的生活方式。
用户在小程序“康复”页面左侧可以看到自己的成就勋章。
勋章展示当前的“等级称号”以及该称号下的具体等级（1-5级）。
下方配有进度条，显示当前等级的升级进度。

## 2. 升级规则
- **基础规则**：患者若连续 7 天保持健康生活（完成所有打卡任务/各项指标正常，具体定义参考系统判定），则等级 +1。若患者某天未健康生活，进度条不清零，但不+1，后续恢复健康生活再在原基础上+1。
- **层级结构**：
    - 共设有 **12 个等级称号**（大段位）。
    - 每个称号下设 **5 个具体等级**（小段位，如：康复新星 I, 康复新星 II, ... 康复新星 V）。
    - 当处于某称号的第 5 级并满足升级条件时，晋升为下一个称号的第 1 级。
- **总耗时**：理论最快通关时间 = 12 * 5 * 7天 = 420天（约14个月），陪伴患者度过漫长的康复期。

## 3. UI 布局描述
- **康复模块（Recovery Page）左侧区域**
  - **组件**：
    - **勋章图标**：包含称号对应的图形元素，动态感强。
    - **等级标识**：当前小段位（如 “Lv.3” 或 五颗星亮三颗）。
    - **进度条**：位于勋章下方，显示 “当前健康天数 / 7”。
- **康复模块（Recovery Page）右侧区域**
  - **文字描述**：您已坚持健康生活了XX天，请继续保持哦！

### 第 3 阶段：精进期
**7. 健康卫士 (Health Guardian)**
**8. 身心自在 (Free Body & Mind)**
**9. 铜墙铁壁 (Iron Will)**


### 第 4 阶段：巅峰期
**10. 康复达人 (Recovery Expert)**

## 5. 数据结构建议 (JSON 示例)

```json
{
  "user_achievement": {
    "current_title_id": 1,        // 当前称号ID (1-12)
    "current_title_name": "康复萌新",
    "current_level": 3,           // 当前称号内的等级 (1-5)
    "consecutive_healthy_days": 4 // 当前累积的健康天数 (0-7)
  }
}
```
