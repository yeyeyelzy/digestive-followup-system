# 3D心脏孪生体接口规范（患者端 + 家属端）

> 版本：v1（2026-02-28）
> 
> 说明：当前小程序已支持“接口优先，失败回退模拟数据”的调试模式。

## 0. 双后端职责划分（推荐）

### 0.1 外部调用原则（小程序）

- 小程序（患者端/家属端）只调用若依后端（BFF 网关层）。
- 智能体后端不直接暴露给小程序。

### 0.2 后端职责

- 若依后端：
  - 鉴权（token）
  - 角色校验（患者/家属）
  - 家属-患者绑定关系校验
  - 组装请求并调用智能体后端
  - 返回统一响应给小程序
- 智能体后端：
  - 计算/推理并返回心脏孪生体关键字段：
    `timestamp`、`heartRate`、`riskLevel`、`anomalyFeatures`
  - 预测接口返回未来 1~3 月趋势数据

### 0.3 内部调用建议（若依 -> 智能体）

- `POST /ai/heart-twin/realtime`
- `POST /ai/heart-twin/forecast`

请求体建议：

```json
{
  "patientId": "10086",
  "scene": "patient|family",
  "source": "ruoyi"
}
```

## 1. 数据目标

3D心脏孪生体页面需要两类数据：

1) 实时状态数据（用于当前跳动、风险颜色、异常特征）  
2) 康复预测数据（用于时间轴 1~3 个月状态切换）

---

## 2. 接口清单

### 2.0 统一响应结构

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

### 2.1 患者端：获取实时状态

- Method: `GET`
- Path: `/system/heart-twin/realtime`
- Query 参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| patientId | string | 否 | 可选；若省略则由 token 对应患者身份解析 |

#### 响应体

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "timestamp": "2026-02-28 10:00:00",
    "heartRate": 96,
    "riskLevel": "medium",
    "anomalyFeatures": ["心动过速倾向", "冠状动脉风险轻度波动"]
  }
}
```

#### 字段约束

| 字段 | 类型 | 说明 |
|---|---|---|
| timestamp | string | 时间戳，建议格式：`yyyy-MM-dd HH:mm:ss` |
| heartRate | number | 心率（bpm），建议范围：30~220 |
| riskLevel | string | 风险等级：`low` / `medium` / `high` |
| anomalyFeatures | string[] | 异常特征列表，可为空数组 |

---

### 2.2 患者端：获取1~3个月预测

- Method: `GET`
- Path: `/system/heart-twin/forecast`
- Query 参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| patientId | string | 否 | 可选；若省略则由 token 对应患者身份解析 |

---

### 2.3 家属端：获取已绑定患者实时状态

- Method: `GET`
- Path: `/api/family/patient/heart-twin/realtime`
- Query 参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| patientId | string | 是 | 家属当前选择的绑定患者ID |

处理规则：
- 若依后端先校验 `familyUserId` 与 `patientId` 是否存在绑定关系。
- 校验通过后，若依调用智能体后端实时接口并透传结果。

---

### 2.4 家属端：获取已绑定患者1~3个月预测

- Method: `GET`
- Path: `/api/family/patient/heart-twin/forecast`
- Query 参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| patientId | string | 是 | 家属当前选择的绑定患者ID |

处理规则：
- 若依后端完成绑定关系校验后调用智能体预测接口。

#### 响应体

```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "monthIndex": 1,
      "monthLabel": "1个月后",
      "heartRate": 92,
      "riskLevel": "medium",
      "recoveryTrend": "stable"
    },
    {
      "monthIndex": 2,
      "monthLabel": "2个月后",
      "heartRate": 84,
      "riskLevel": "low",
      "recoveryTrend": "improve"
    },
    {
      "monthIndex": 3,
      "monthLabel": "3个月后",
      "heartRate": 78,
      "riskLevel": "low",
      "recoveryTrend": "improve"
    }
  ]
}
```

#### 字段约束

| 字段 | 类型 | 说明 |
|---|---|---|
| monthIndex | number | 月份索引，取值：1 / 2 / 3 |
| monthLabel | string | 展示文案，如：`1个月后` |
| heartRate | number | 预测心率（bpm） |
| riskLevel | string | 风险等级：`low` / `medium` / `high` |
| recoveryTrend | string | 康复趋势：`improve` / `stable` / `worse` |

---

## 3. 前端映射规则

- 风险颜色：
  - `low` → 绿色系
  - `medium` → 橙色系
  - `high` → 红色系（并触发震动提醒）
- 跳动频率：`beatPerSecond = heartRate / 60`
- 时间轴：
  - 第 1 档对应 `monthIndex = 1`
  - 第 2 档对应 `monthIndex = 2`
  - 第 3 档对应 `monthIndex = 3`

---

## 4. 错误码建议

| code | 含义 | 前端处理 |
|---|---|---|
| 200 | 成功 | 正常渲染 |
| 400 | 参数错误 | Toast 提示“参数错误”并保留上一帧数据 |
| 401 | 未登录/登录失效 | 引导登录 |
| 404 | 患者不存在 | Toast 提示“患者信息不存在” |
| 500 | 服务异常 | 回退模拟数据并提示“接口异常，已切换调试数据” |
| 403 | 无访问权限/未绑定 | 家属端提示“当前患者未绑定或无权限查看” |

## 6. 与当前代码对应关系

- 前端请求封装：`patient/api/requests.js`
  - `getHeartTwinRealtime(patientId)`
  - `getHeartTwinForecast(patientId)`
- 页面消费：`patient/pages/heartTwin/index.js`

- 前端请求封装：`family/api/requests.js`
  - `getFamilyHeartTwinRealtime(patientId)`
  - `getFamilyHeartTwinForecast(patientId)`
- 页面消费：`family/pages/heartTwin/index.js`

后端按本文字段返回后，页面无需改动即可从模拟数据切换到真实接口数据。
