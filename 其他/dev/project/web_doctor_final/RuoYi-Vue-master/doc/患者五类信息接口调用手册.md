# 患者五类信息接口调用手册（家属端查询某患者）

## 1. 适用范围
- 目标：查询某个患者的**饮食、行为、服药、生活方式、出院小结、出院医嘱**。
- 适用后端：`RuoYi-Vue-master`。
- 推荐调用方：家属端（已绑定患者）。

---

## 2. 认证与基础信息
- 基础地址：`http://{host}:8080`
- 认证方式：`Authorization: Bearer {token}`
- Token 获取：`POST /api/family/login`
- 内容类型：`application/json`

### 2.1 登录接口（获取 token）
- 接口号：`FAM-AUTH-001`
- 路径：`POST /api/family/login`
- 请求体：
```json
{
  "username": "家属手机号或账号",
  "password": "密码"
}
```
- 成功返回：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "token": "eyJ..."
  }
}
```

---

## 3. 调用顺序（推荐）
1. `FAM-PT-000`：查询已绑定患者列表，拿到 `patientId`。
2. `FAM-PT-001~004`：按需查询饮食/行为/服药/生活方式。
3. `FAM-PT-005`：查询出院小结列表，拿到 `doctorsAdviceId`。
4. `FAM-PT-006`：根据 `doctorsAdviceId` 查询出院医嘱详情。

---

## 4. 接口清单（含接口号）

### 4.0 查询已绑定患者列表
- 接口号：`FAM-PT-000`
- 方法/路径：`GET /api/family/patients`
- Query：无
- 返回类型：`AjaxResult`
- 成功返回示例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "patientId": 10001,
      "patientName": "张三",
      "phonenumber": "13800000000"
    }
  ]
}
```

---

### 4.1 查询患者饮食记录
- 接口号：`FAM-PT-001`
- 方法/路径：`GET /api/family/patient/diet`
- Query 参数：
  - `patientId`(Long, 必填)
  - `pageNum`(int, 建议)
  - `pageSize`(int, 建议)
  - `date`(yyyy-MM-dd, 可选)
- 返回类型：`TableDataInfo`
- 返回示例：
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 1,
  "rows": [
    {
      "dietId": 1,
      "patientId": 10001,
      "patientName": "张三",
      "date": "2026-02-20",
      "dietDescription": "早餐燕麦+鸡蛋",
      "dietPictureUrl": "/profile/upload/2026/02/a.jpg",
      "kcal": 420,
      "feel": "状态良好",
      "replay": "本周控盐",
      "confusion": "晚餐加餐如何控制"
    }
  ]
}
```

### 4.2 查询患者行为记录
- 接口号：`FAM-PT-002`
- 方法/路径：`GET /api/family/patient/behavior`
- Query 参数：
  - `patientId`(Long, 必填)
  - `pageNum`、`pageSize`、`date`(可选)
- 返回类型：`TableDataInfo`
- `rows` 关键字段：`behaviorId, patientId, patientName, date, frequency, strength, duration, type, feel, replay, question`

### 4.3 查询患者服药记录
- 接口号：`FAM-PT-003`
- 方法/路径：`GET /api/family/patient/medicine`
- Query 参数：
  - `patientId`(Long, 必填)
  - `pageNum`、`pageSize`、`date`(可选)
- 返回类型：`TableDataInfo`
- `rows` 关键字段：`medicineId, patientId, patientName, date, flag, symptom, replay, question`

### 4.4 查询患者生活方式记录
- 接口号：`FAM-PT-004`
- 方法/路径：`GET /api/family/patient/living`
- Query 参数：
  - `patientId`(Long, 必填)
  - `pageNum`、`pageSize`、`date`(可选)
- 返回类型：`TableDataInfo`
- `rows` 关键字段：`livingId, patientId, patientName, date, neededChange, isImproved, feel, question`

### 4.5 查询患者出院小结
- 接口号：`FAM-PT-005`
- 方法/路径：`GET /api/family/patient/discharge`
- Query 参数：
  - `patientId`(Long, 必填)
- 返回类型：`AjaxResult`
- 成功返回示例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "admissionNumber": 98765,
      "patientId": 10001,
      "patientName": "张三",
      "admissionDate": "2026-01-08",
      "dischargeDate": "2026-01-20",
      "dischargeDiagnosis": "慢性心衰",
      "majorTestResult": "NT-proBNP明显下降",
      "doctorsAdviceId": 5566
    }
  ]
}
```

### 4.6 查询出院医嘱详情
- 接口号：`FAM-PT-006`
- 方法/路径：`GET /system/advice/{doctorsAdviceId}`
- Path 参数：
  - `doctorsAdviceId`(Long, 必填，来自 `FAM-PT-005` 返回)
- 返回类型：`AjaxResult`
- 成功返回示例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "doctorsAdviceId": 5566,
    "patientId": 10001,
    "patientName": "张三",
    "medicationRegimen": "每日早晚各一次",
    "reviewPlan": "2周后门诊复查",
    "notice": "低盐饮食，规律作息"
  }
}
```

## 5. 通用返回格式说明

### 5.1 分页列表（TableDataInfo）
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 123,
  "rows": []
}
```

### 5.2 普通结果（AjaxResult）
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

- `code=200`：成功
- `code=500`：业务异常或系统异常
- 常见 HTTP：`401` 未登录/Token 无效，`403` 无权限

---

## 6. 注意事项（重点）
1. 家属查询接口均要求家属与患者已绑定；未绑定或 `patientId` 缺失时，后端通常返回空列表（`rows=[]` 或 `data=[]`），不是报错。
2. 时间字段格式统一建议使用 `yyyy-MM-dd`。
3. `FAM-PT-001~004` 为分页结构，前端应优先读取 `rows`，并结合 `total` 做分页。
4. `FAM-PT-006` 走 `/system/advice/{id}`，该接口在后端带权限控制（`system:advice:query`）；若家属角色无此权限会返回 `403`。
5. 若需“按患者ID直接查医嘱列表”，建议后端新增家属专用接口（如 `/api/family/patient/advice`），避免依赖后台权限点。

---

## 7. 最小可用调用示例（伪代码）
```text
1) token = POST /api/family/login
2) patients = GET /api/family/patients
3) patientId = patients.data[0].patientId
4) diet = GET /api/family/patient/diet?patientId=...&pageNum=1&pageSize=20
5) behavior = GET /api/family/patient/behavior?patientId=...&pageNum=1&pageSize=20
6) medicine = GET /api/family/patient/medicine?patientId=...&pageNum=1&pageSize=20
7) living = GET /api/family/patient/living?patientId=...&pageNum=1&pageSize=20
8) discharge = GET /api/family/patient/discharge?patientId=...
9) advice = GET /system/advice/{discharge.data[0].doctorsAdviceId}
```
